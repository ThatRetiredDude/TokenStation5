# Roadmap

The project's punch list (what's done, what's open, what's next, with the
console's numbers build by build) is kept on the `roadmap` branch:

https://github.com/ThatRetiredDude/TokenStation5/blob/roadmap/docs/ROADMAP.md

It changes with every pull request, so it lives in a pull request of its own
([#18](https://github.com/ThatRetiredDude/TokenStation5/pull/18)) that stays
open on purpose. This file on `main` only points there, so the two can't say
different things. [FEASIBILITY.md](FEASIBILITY.md) is where the project
started: the hardware, the memory budget and the risks.
