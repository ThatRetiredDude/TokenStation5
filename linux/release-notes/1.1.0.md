- Users. Give someone else their own account: the chat page and the API with their own keys, and only what you allow (web search, an app's own tools, tokens a day, the longest reply). Each user's chats are their own, on every device with their key; you can read them only if that was chosen when the user was made, and they see it in their Settings. Users never get ts5-tui or the browser terminal; an editor or any OpenAI-compatible app works with their key. The Access page (F6) lists users with their keys: U adds one, Enter changes what they may do, P pauses, D removes.
