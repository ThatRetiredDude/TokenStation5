**ts5-tui**

- `/update` installs the newest TokenStation5 from ts5-tui. It asks first; then ts5-tui closes (the model it loaded stops), downloads the newest build and installs it the way this copy was installed (apt, dnf, pacman, or the portable build's install.sh; sudo asks for your password in the same window), and opens again with the model loaded back. When the newest build is the one you have, it says so and installs nothing. If the update fails, what went wrong stays on screen until Enter, then ts5-tui opens again. `ts5-tui --update` does the same without the app.
- `/feedback` opens on the window to send the report, not on the report itself. Enter sends it; **Read it first** shows exactly what would be sent, and brings you back. Adding the chat or leaving the log out also brings you back to that window.
- **Connect a phone** says when a new key's QR code can't open the chat page through Tailscale. With the server off (no model loaded), or Tailscale off or not connected yet, the code holds this network's http address, or one nothing answers, and looked just like a good one. Now the code's window says so first and in its title, with what to do (load a model, turn Tailscale on in Access, then make the key again); the Access row warns before Enter, and a key made from the phone's Controls gets the same note.
