The first numbered release of TokenStation for Linux: away from home, in a browser, and on GitHub. From here on Linux has its own semantic versions (MAJOR.MINOR.PATCH), apart from the PS5 title's.

- Tailscale built in. Turn it on from the Access page (F6), scan the QR code with your phone (or open the link) to sign in, and the PS5 joins your tailnet as its own device. Nothing else to install, and nothing on the PS5 opens to the internet.
- Connect a phone. One press makes a key and puts it inside a QR code: scan it with the phone's camera and the chat page opens, already signed in, with nothing to type. Arrow keys show the browser terminal's code the same way, then the address and the key for any OpenAI-compatible app. Tap the text under a code to copy it. It works at home and on mobile data.
- SSH from your tailnet. An optional switch on the Access page lets you ssh into the PS5 from your own devices, using the PS5's normal SSH login. It's off by default.
- A chat page. Open the PS5's address in any browser from your tailnet and chat with the loaded model, thinking included. Opened from Connect a phone it is signed in already, and it asks once whether to save the key to your passwords; opened by hand it asks once for a key. Chats (top left) lists your chats: tap one to go on with it, delete one, or start a new one. Each chat is its own conversation, and the model remembers it all when you go back to it. Your chats stay in that browser only. Nothing to install on the phone.
- A home-screen app. Add the chat page or the browser terminal to your phone's home screen: it gets the TokenStation5 logo, opens on the logo while it connects, and is signed in from the first time you open it, with no key to type again.
- A secure address. Turn on MagicDNS and HTTPS Certificates in your tailnet's admin console (DNS page) and TokenStation gets its own certificate for its tailnet name by itself, and renews it. The QR codes then open https://your-ps5-name.your-tailnet.ts.net/: no browser warning, and your phone's passwords can fill in the key.
- A browser terminal. ts5-tui itself in a web page, for a laptop or tablet with no SSH client. Off by default: turn it on from the Access page, and Enter there gives you a QR code that opens it signed in. Only your tailnet's devices can open it, each time with a key, and a closed tab or lost signal leaves the answer running. A key bar under it gives a phone Esc, Tab, the arrows and F1 to F7.
- GitHub, connected with a QR code. A new Connectors page (F7): scan the code with a phone signed in to GitHub, enter the short code, and pick which repositories TokenStation5 may use. No token to paste. The model's GitHub tool then reads those repositories freely and asks before every change (a branch, a file, a pull request, an issue, a comment), showing what it will send and how much of a file it replaces. "My repositories" means the ones you picked.
- Your chats in ts5-tui: Ctrl+O lists them, newest first. Open one to go on with it (the model gets that chat and nothing from the others), delete one, or start a new one, with the keys or a click. The browser terminal's key bar has Chats and New chat buttons.
- Chat steering: while the model works, Enter sends a note it sees at its next step, and Tab queues a message for after the answer.
- /feedback: a report you read first, cleaned on the machine, sent to TokenStation's private feedback service (never public). Type /feedback, what went wrong and an email if you want a reply, then Enter.
- Clearer QR codes: drawn in solid blocks with a wider border and stronger error correction, so phone cameras read them; in a small window a red line says to make it bigger. Click the sign-in link, or press C, to copy it.

Notes:
- Apps, the chat page and the browser terminal reaching TokenStation over your tailnet need a key from the Access page.
- If your phone can't find the PS5 by name, use the 100.x address shown on the Access page.
- iPhone: a home-screen app can't use your saved passwords (an iOS limit). Add it from Safari after signing in there and it opens signed in. If you change the key, delete the icon and add it again.
- GitHub: the app can read and write code, pull requests and issues and read CI results. It can't change workflow files or a repository's settings. D on the Connectors page disconnects.
