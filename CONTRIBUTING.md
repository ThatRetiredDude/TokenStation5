# Contributing

Bug reports, test results from your own PS5 and ideas are welcome as
[issues](https://github.com/ThatRetiredDude/TokenStation5/issues).

Code is a different matter. TokenStation5 is dual-licensed (see
[LICENSING.md](LICENSING.md)), and the copyright holder must be able to
offer every line under PolyForm, under the GPL as part of the PS5 title, and
under a commercial license. That only works if contributed code can be
relicensed the same way. So, for now:

- Pull requests to `engine/`, `ps5/`, `linux/` and `scripts/` are accepted
  only from contributors who agree, in the pull request, to this grant:
  *"I own this contribution and license it to the TokenStation5 copyright
  holder under the Apache License 2.0, with permission to relicense it under
  any terms, including the project's PolyForm, GPL and commercial
  licenses."*
- Fixes to the wiki (`wiki/`) and docs are welcome under the same grant; a
  typo fix needs no ceremony.
- Code copied from GPL projects (PS5_Vulkan, the payload SDK, PS5LM, espeak-ng
  and others) can't be accepted anywhere in the repository.
- Permissively licensed code (MIT, BSD, Apache-2.0, zlib) is fine if its
  notice goes into [NOTICE.md](NOTICE.md).
